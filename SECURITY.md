# Security Policy

## Supported versions

Security fixes are developed against the latest released version. The 0.x series is alpha software and may change without a compatibility guarantee.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If private reporting is unavailable, contact the maintainers through a verified contact method listed on the repository profile.

## Data handling

FixAtlas is designed to process logs locally. It does not send logs over the network, store them, or execute suggested commands. Reports shared with maintainers should be sanitized first.
