# Changelog

All notable changes to FixAtlas are documented here.

## [0.1.0] - 2026-11-11

### Added
- Offline Python CLI with `explain`, `list`, `search`, `doctor`, `validate-registry`, and optional `mcp` commands.
- Deterministic literal-signature matching with transparent match signals.
- Nine initial diagnostic rules spanning npm, Python, Git, C/C++, and Gradle.
- JSON output and dependency-free agent tool functions.
- Optional official-SDK MCP server with read-only explain, search, list, and capability tools (Python 3.11+).
- Custom JSON registry loading and validation.
- Coding-agent starter assets: a diagnostician agent profile, reusable diagnosis skill, safety rules, and MCP client configuration example.
- Project governance assets including MIT license, citation metadata, support/security policies, issue forms, PR template, Dependabot, CodeQL, CI, and release automation.
- Repeatable GitHub bootstrap script for repository creation/reuse, release-tag push, topic metadata, Discussions/Issues, merge preferences, and issue labels.
- Input-size limits, no-network behavior, and no-telemetry defaults.
- Pytest suite, cross-platform GitHub Actions CI, CodeQL workflow, issue templates, and contribution guidance.
